# 自绘车机界面

更新：2026-11-07。首页按有效显示/安全区域布置 Dock、地图与音乐卡。音乐卡宽度约为安全区域25%，封面铺满背景，并叠加日夜可读性遮罩。

音乐卡显示 MediaSession 实际提供的元数据、进度和播放状态，提供上一曲、播放/暂停、下一曲及支持时的收藏。收藏使用播放器自定义 action 或 heart/thumb rating，状态以回调为准。播放器真实页面可展开，收起后继续后台播放。

自绘播放列表和播放模式 UI 及相关无效适配已删除，不再宣称可控制 QQ 音乐专用队列/循环接口。通知使用权只用于 MediaSession，不等于第三方专用接口授权。方向盘控制与语音见[输入与语音](INPUT-AND-VOICE.md)。

地图卡片、全屏和返回按钮见[地图](MAP-PROVIDERS.md)。应用页列出支持且已安装的应用。设置包含默认地图/音乐、自动播放、主题与壁纸；巡航跟随地图。App“主题与外观”仅改变手机 App，车机主题在车机里设置。

连接时首页用阶段卡片替换首次配对提示，成功/异常分别标绿/红。控制会话连接、视频写出和真实画面/声音是不同状态，不能用“已连接”代表全部成功。日志和诊断解释见[连接诊断](HANDSHAKE-DIAGNOSTICS.md)。

根目录截图是历史外观示例，不代表当前全部设置。实现：`CarHomeScreen`、`MusicBridge`、`CarUiCaster`。
