# 当前车机界面

更新：2026-11-02。

首页在接收端有效显示区域内布局 Dock、地图和音乐卡片。音乐卡宽度为安全区域宽度的 25%；专辑封面裁剪填满整个音乐卡片背景，并叠加日夜可读性遮罩，不使用独立的小封面布局。

## 音乐

卡片显示播放器提供的歌曲、封面、时长、进度与播放状态。上一首、暂停、下一首、收藏、队列及循环模式依赖实际 MediaSession 能力。收藏可通过自定义 action 或 heart/thumb rating 实现，状态以播放器回调为准；取消后应允许再次操作。

QQ 音乐有专用适配入口，但实机专用服务返回过 code=5（No permission），当前没有 QQ 开放平台应用授权。因此不能宣称专用队列与模式接口已可用，也不把入口存在等同于已获得权限。播放器未暴露相关能力时展示不支持。

音乐卡可展开当前播放器的真实应用界面，收起后继续后台播放；这与卡片自有的元数据与按钮是两种操作入口。系统通知使用权用于获取 MediaSession，不等于 QQ 专用接口授权。

## 地图与设置

地图卡片与全屏共用地图任务，切换不重启导航。全屏通过主页操作返回。地图详情见[地图说明](MAP-PROVIDERS.md)。

设置提供默认地图、音乐应用、连接自动播放、主题、壁纸等。巡航行为跟随地图应用自身设置；HyperCar 不再维护独立的自动巡航定时器。自动主题支持日夜切换。

更多应用列出受支持且已安装的音乐应用。`requestUI` 请求车机回到原生界面并保留连接；已在 WinPlay 验证，当前宝马版本效果仍需实车确认。
