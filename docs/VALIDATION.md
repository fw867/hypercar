## 2026-11-14 iAP2 媒体卡补齐（563）

对照 [CarPToCarL 媒体字段](https://github.com/jjuugk/CarPToCarL/blob/main/app/src/main/java/io/github/shaonialife/carptocar/iap2/Iap2NowPlaying.kt)、[封面数据报](https://github.com/jjuugk/CarPToCarL/blob/main/app/src/main/java/io/github/shaonialife/carptocar/iap2/Iap2ArtworkTransfer.kt)及其蓝牙/虚拟链路实现，核实本项目原先蓝牙没有实际媒体订阅应答、Wi-Fi 只发空态、文件传输会话虽声明但未消费。原先 `0x5001` 的停止名称错误，现校正为更新，停止为 `0x5002`；该误标不能倒推为历史方向盘切歌根因。

- 两种传输共用订阅状态机，认证前只记录订阅；取消、传输重建及会话结束不沿用旧订阅。空态先应答，真实元数据晚到后补推；曲目/状态变化去重，播放进度最多约五秒更新一次。数据来自既有播放器 MediaSession 快照，包含歌名、歌手、专辑、应用、时长、进度和播放状态；无法取得的随机/循环状态不虚构。
- 专辑字段为 `0x0006`，`0x001A` 只承载实际可传封面的单字节编号。图片在独立工作线程缩放为最长边 320 像素的 JPEG，上限 256 KiB，不在 iAP2 接收线程进行图片压缩或 Binder 查询。
- 文件会话必须由对端本轮同步表声明，按协商 ID 路由，不能固定假定 12。先发媒体编号及 SETUP，收到对应 START 后才分块；每次最多两块、每块不超协商长度。成功/拒绝/暂停/超时及迟到旧编号均有处理，换图取消旧事务；可选文件包最多重试一次，不因封面重试耗尽主动杀控制链。未收到 ACK 不伪造确认，也不绕过共享窗口。
- 一条传输不循环复用封面编号；255 个编号耗尽后仅保留文字，避免缓存串图。日志不输出曲名、图片内容或凭据。

新增 21 项测试，覆盖字段/单层 CSM、蓝牙早订阅与停止、Wi-Fi 真实信息及封面收发、对端文件会话、协商包长、START/超时/拒绝/换图/重建/编号耗尽与有限重试。完整 JVM 回归 443 项通过，Release/Lint 通过并覆盖安装；原生实现本轮未改，沿用上次 175 通过、1 忽略记录。此处尚无新增 BMW/奔驰/大众实车媒体卡显示及封面成功证据；仅模拟通道通过不能宣称车机已显示，也不改变现有屏幕 SETUP 拒绝的待验证结论。

## 2026-11-14 项目代码审计

本轮从自动/手动控制、蓝牙与 Wi-Fi 建链、身份快照、网络租约、资源与媒体协商、JNI 描述符交接和退出清理核对主要路径，并运行完整现有回归。属于静态检查与软件回归，不等同于逐行证明或全部车型实测。

| 发现 | 处理与边界 |
|---|---|
| 蓝牙 worker 已占用会话后，身份读取、通道及会话构造发生异常可绕过原有 finally，遗留 socket 和运行占位。 | 将初始化纳入同一 try/finally，通道未完成创建也回收 socket、引用和占位。关闭时的诊断失败不再阻断清理；JVM 编译与回归通过，Android 蓝牙构造失败注入尚未现场验证。 |
| RTSP 非法 Content-Length 被当成零；极端长度可能溢出，无边界积累会持续占用内存。 | 显式拒绝非法、冲突和过大长度，限制单条头部 64 KiB、正文 16 MiB；分片与流水消息保留。读取器遇到坏帧退出并释放等待事务，测试验证不必等待事务超时。正常空正文仍可省略长度。 |
| plist 自引用/过深引用没有终止条件，共享子树可放大解码内存。 | 深度上限 128、展开节点预算及 32 MiB 复制负载预算；对象不得指向头部、偏移表或 trailer，集合引用先校验范围。合法共享引用继续支持；循环、过深和预算超限均返回错误。 |
| 会话文档仍记载旧的 ACL 强制重播与设备标识等同 BSSID 的规则，架构文档未更新实验麦克风范围。 | 按当前实现校正，避免后续维护重新引入发现空窗或错误网络拒绝。 |

已核对的正常路径继续保留：手动启动独立于自动开关；手动停止的十分钟自动暂停；同网络健康 mDNS 持续注册；请求所有权与设备标识分离；各车型档案隔离。未据无证据推断修改 ID9/奔驰的 SETUP 顺序、编码或抢占参数，实车待验证项仍见下文。

- **网络和停止行为。** 两轮仍有重复入网，需用 655 及之后版本验证；媒体协商期间未记录请求 `onLost`。一轮持续控制通信超过一分钟，另一轮最终为用户手动停止且 TEARDOWN 成功。手动停止后的休眠拒接是既有十分钟暂停策略，不等同车机拒绝协议。最后一轮尚在等入网结果即导出，不能按完整失败样本计。
