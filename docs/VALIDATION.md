### 设备身份与固定值复核

| 字段或路径 | 判断与处理 |
|---|---|
| AirPlay deviceID / macAddress | 固定地址已移除，均使用本次解析出的同一手机标识。 |
| 手动地址优先级 | 原 AirPlay 启动先取自动地址，可能绕过手动值，与 iAP2 不一致；现统一使用同一解析快照，遵循手动、自动、稳定后备的来源规则。 |

| 无效地址 | 自动和手动来源统一过滤系统占位、全零、广播及格式错误地址；有效手动值仍优先。 |

| UUID 与配对身份 | 协议服务 UUID 为固定服务标识，设备问候 UUID 从手机身份派生；配对身份持久化，会话 UUID 每轮生成。用途不同，不能强制改成同一个 UUID，也未重置已有配对记录。 |
