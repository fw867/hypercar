# 会话控制与自动连接

更新：2026-11-07。当前机制不构成二次上车成功率保证；真实媒体结果见[验证](VALIDATION.md)。

## 首次使用与待机

按权限、画面来源、配对顺序引导。StartupRequirements统一读取运行时权限、系统开关与来源依赖；自绘UI必须安装/运行/授权Shizuku，CarWith必须检测到已启用的com.miui.carlink。启动与自动连接入口使用同一就绪条件，来源变化后重新核实，不用旧的授权结果代替检查。

自动模式把持久待机身份与单轮会话分开。目标MAC是车机身份边界，同名Wi-Fi不能共用配对身份。已授权的系统配对、长期AirPlay身份和临时端点各自管理，不因每次失败就全部清空。

## 发现和蓝牙

主监听使用cafe服务，附加CarPlay Phone标记UUID为2d8d2466-e14d-451c-88bc-7301abea291a，动态RFCOMM通道复用过滤及会话处理。主服务优先、附加服务独立重试，开关不影响主监听；注册了SDP/EIR不等于车机已接受标记或实车重连改善。

增强发现只在已有系统配对设备中做定向SDP，不配对或连接陌生设备；经典可发现窗口有界、按目标与当前占用限制，并在开始连接、停止或超时时清理。worker发布socket和Wi-Fi handoff使用同一门控，旧代次回调不能迟到接管。

BMW默认不主动拨iAP2、不主动断HFP/A2DP。其它档案依赖自身策略，不把“蓝牙已连接”一律当作要拆ACL的理由；音频配置保护不能拆掉正在承载业务的RFCOMM。

## 主动Wi-Fi与邀请

正常邀请和当前iAP2端点优先。启用主动开关、车型允许、配对身份/目标匹配且Wi-Fi已绑定时，网络稳定至少10秒后可尝试。端口可连接不证明车机已激活。

控制连接或视频TCP前失败时，只回收失败引擎。连接失败及其它暂态失败按10/20/40/60秒退避，最后两次为60秒间隔，最多5次自动恢复，耗尽后等待新邀请；范围绑定Network和车机MAC。若无邀请的主动连接已获RECORD确认、却在初始资源确认前结束，则本轮同一车机/网络只等待新邀请，不定时重放同一激活；新连接轮次或新网络仍可作首次主动尝试。这是按阶段收敛恢复，不代表收到明确拒绝码。

媒体失败可暂用同范围仍可连接候选，控制端口失效则清除后重新发现。真实邀请或新iAP2端点可提前继续。未配对网络、开关关闭、车型禁用或其它车机占用时仍只等待邀请。

555–557“首次失败后整轮只等邀请”已被后续有界重试替代。大众仍要求当前网络20秒内ctrl邀请，奔驰禁用无本轮参数的主动捷径；这些不施加给BMW。详情见[档案](HEADUNIT-PROFILES.md)。

## 停止、清除与退出

主动停止当前有效轮次会暂停自动连接10分钟；后续ACL/Wi-Fi事件不能绕过。用户明确手动启动/重试或重新开启自动连接时，会清除旧暂停记录、取消恢复定时器/闹钟并恢复网络监听，不把旧暂停带入新一轮失败回退。预检不通过的启动请求不会清除暂停。

607 起首页停止操作携带所显示的 connectionAttemptId，并在会话控制锁内再次核对轮次及状态；旧轮次、失败/结束后的迟到停止和重复停止不能创建或延长暂停。按钮按连接轮次与操作状态分组，启动→停止、协商→已连接等变化会取消旧按压，避免手指按下时的启动按钮在松开时变成停止。自动连接开关变更同样串行处理，排队的旧开关请求由最新请求失效。自动断链和建链失败不创建暂停。

自动关闭时释放监听及发现资源；自动待机可保留身份声明但不扫描、不拨号、不执行iAP2握手。

单车清除按明确MAC处理配对/凭据；全部清除是另一个高级操作。停止与系统解绑、删除身份不能混为一谈。媒体任务、网络租约、端点及UI生命周期按会话代次回收；正常退出先停媒体，再有界TEARDOWN，异常退出不伪造优雅成功，见[协议](PROTOCOL.md)。

## 设置与状态

首页自动连接快捷开关与设置使用同一持久值；会话连接时显示阶段卡片。深浅主题/跟随系统仅改变手机App，车机主题在车机设置。连接诊断见[阶段说明](HANDSHAKE-DIAGNOSTICS.md)。


## BOX-OFF 重连机制移植（610）

掉线后的会话级恢复采用2/5/10/30/60秒共五次预算。同一恢复链上的协商失败继续消耗预算，不因控制层connected清零；当前视频管线实际写帧后开始观察，维持约120秒后断开才重新补足预算。手动启动、关闭自动模式或换到另一车机可清除旧预算。耗尽后保留待机，不阻止真实车机入站；Wi-Fi能力变化通知不能绕过正在执行的退避或耗尽预算。首次从未建立链路的失败仍不直接启动掉线恢复链。

会话内已知Wi-Fi主动激活仍保留10/20/40/60/60秒间隔，但最多五次，不再无限重放；已确认的激活关闭仍优先要求新邀请。该限制不禁止新Network、新车、手动新轮次的首次尝试，也不把所有已配对车机恢复成只等邀请。

入网前读取实时Wi-Fi句柄、SSID、有效本机地址、到车机的非默认路由；端点deviceIdentifier为MAC时核对BSSID。地址已证实或当前轮次持有租约时可复用，只有缓存SSID/句柄不能授权复用。被ROM隐藏的BSSID可通过已授权Shizuku读取wifi status；不修改系统网络或身份。多Wi-Fi无法唯一匹配时不随意选择第一条，失败后也不回落到未经核实的网络。已有NetworkSpecifier请求若仍持有同一网络则保留。

终止清理、网络绑定及核心启动共用会话控制锁。失败回调先排队并核对轮次，作废socket租约、取消/等待旧连接，再释放本轮引擎/网络。旧FD未获当前轮次接管时立即关闭；旧协程finally不能清掉新轮次connecting。保留既有地图任务与导航状态，继续通过已有UI生命周期代次释放编码器及Surface；本版没有另启CarWith实例或新增视频重建实验。手动停止后的十分钟自动暂停与iPhone身份监听策略不变。
