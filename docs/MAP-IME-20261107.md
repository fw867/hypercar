# 全屏地图键盘显示修正

代码同步到 `07fec45` 后检查：地图使用 `MapPreview` 的持久虚拟屏，全屏时切换 Surface 并直接编码该屏；手机主屏上的输入法窗口不会进入车机视频。

2026-11-07 手机现场读到 `hypercar-map` 的 displayId=310，`IWindowManager.getDisplayImePolicy(310)=1`（FALLBACK_DISPLAY）。设置为 0（LOCAL）后读回 0。原实现创建 TRUSTED / OWN_FOCUS 虚拟屏，但没有设置 IME 策略；独立焦点并不能保证键盘显示在副屏。

修正在 Shizuku UserService 创建受信任虚拟屏后、启动 Activity 前调用 `setDisplayImePolicy(id, LOCAL)`，并读回结果。调用期间清除传入 Binder 身份以使用 shell 权限，最后恢复。未获得 TRUSTED 的降级屏跳过设置；ROM 拒绝时保留可用画面并记录 `ime=unavailable(...)`。创建结果中 `ime=local` 表示读回成功。

只调整本服务创建的虚拟屏，不修改主屏、输入法选择、全局设置或 CarWith 的显示策略。地图卡片与全屏继续使用同一虚拟屏，Surface 切换不重建地图任务。

依据：[AOSP 多屏输入法支持](https://source.android.com/docs/core/display/multi_display/ime-support)、[WindowManagerService 的权限与可信显示检查](https://android.googlesource.com/platform/frameworks/base/+/android-16.0.0_r2/services/core/java/com/android/server/wm/WindowManagerService.java)。

后续端到端检查：全屏地图点击搜索、车机键盘显示及触摸输入、收起键盘、返回首页再进入地图。系统策略读回成功不能代替输入法渲染和触摸验证。

单元测试：221 项通过，0 失败、0 错误。此次未改动 Rust、iAP2 或视频尺寸/触摸坐标映射。

## 安装及现场结果

0.1.0.565 / 10565 已安装，自动重连后首页与地图创建日志均为 `ime=local`。旧屏运行中切换策略时曾出现输入法未绑定，两端都无键盘；因此不能将策略写入成功当成显示成功。

新屏在 Activity 启动前设置策略后，用户确认键盘已显示。系统最终读到 `mCurDisplayId=314`、`mSelectedDisplayId=314`、`mInputShown=true`；地图屏的 `mImeWindow=InputMethod`、`mIsImeShowing=true`，输入目标为高德 UcarMapActivity。已确认输入法实际落在地图虚拟屏。系统日志也记录了输入法窗口接收触摸；完整输入内容、收起和再次进入仍可继续回归。

Release 构建成功；Debug Lint 无错误（47 Warning、2 Information）。
